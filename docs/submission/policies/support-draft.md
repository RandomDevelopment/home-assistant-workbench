# Get help with Home Assistant Workbench

Draft support page for **Random Development**. Not yet hosted at a verified public support URL.

For plugin bugs or feature requests, open **Feedback** in the connection manager or ask the installed plugin to submit a report. You get a tracking ID and can check maintainer replies. You do not need a GitHub account or a connected Home Assistant installation.

Include the task you tried, expected result, actual result, relevant versions, and steps to reproduce. Never include credentials, a private household URL/address, or device history. Logs are not attached automatically. Installation ID and known Core version are optional. Feedback expires after 90 days, and you can delete your own report sooner.

For setup, follow the Getting Started guide and the repository README. To report an issue publicly, use the verified project repository after transfer. Public issue text is visible to everyone. Each separately deployed copy’s feedback stays with that copy’s maintainer.

The publisher selected **GitHub issues** for public support, with the built-in Feedback form for connected users, and confirmed **services@randomdevelopment.biz** for private security or data-deletion requests. The implemented public support document is `docs/support.md`. No response-time promise has been chosen. Urgent physical-home problems should be handled through your own Home Assistant controls and appropriate local support.
