# Record a real Workbench demonstration

This is a recording plan, **not a recorded demo**. Use the exact version being submitted, a dedicated reviewer ChatGPT account, and sample HA installations named Demo Home and Demo Workshop. Keep credentials, household URLs, unrelated chats, and private device data off screen. Use a test lamp for the authorized action.

1. Start recording the ChatGPT window and connection manager. Show the plugin selected in a fresh conversation. If connection is required, record the connection screens before and after authorization, pause capture during credential entry, and disclose that pause.
2. Ask: “Inspect Demo Home and summarize its Home Assistant version and available capabilities. Do not change anything.” Show the actual named installation, returned version, and unavailable capabilities.
3. Ask: “Compare Demo Home and Demo Workshop. What versions and capabilities differ? Do not change either.” Show real results for both and that their installation IDs remain separate.
4. Ask: “Investigate compatibility of my tracked integration on Demo Home. Check its installed version against documentation, release notes, and GitHub issues.” Show the saved repository/version, real citations, and any unknown compatibility. Do not fabricate a successful diagnosis.
5. Ask: “On Demo Home, turn off Demo Lamp. I authorize this action. Resolve the light, prepare it, execute it, and check the result.” Show the exact draft, the actual execution, and a readback of the test light. Use only an authorized harmless fixture.
6. Ask: “Send this feature request to Workbench: Please support bounded history queries. Do not attach installation context. Then show me its saved status.” Show its real tracking ID and the feedback view. Delete the test report after recording if authorized.
7. Ask: “Which rooms did my phone move through during the last six hours?” Show the unsupported-history explanation. Do not substitute current `last_changed` timestamps for a historical answer.

Leave prompts and results readable. Play back the saved recording to check coverage, text size, sound if used, and absence of secrets. Host it at a publisher-controlled URL reviewers can open and play without requesting access. Verify playback there and write the actual URL to `extensions.com.openai.review.demo_recording_url`.

No recording tool is currently available in this session. Use your screen recorder; screenshots alone do not satisfy the video requirement. Reviewer credentials and sign-in instructions belong in secure dashboard fields, never this directory or the public listing.
