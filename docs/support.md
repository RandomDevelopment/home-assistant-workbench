# Get help with Home Assistant Workbench

Home Assistant Workbench is an independent project from **Random Development**. Public support uses [GitHub issues](https://github.com/RandomDevelopment/home-assistant-workbench/issues). Search existing reports first, then open a bug report or feature request.

Describe what you tried, what you expected, what happened, relevant versions, and steps to reproduce. Public issue text is visible to everyone. Leave out tokens, passwords, private URLs, addresses, household history, and sensitive logs.

For private security or data-deletion requests, contact **services@randomdevelopment.biz**. Include enough non-sensitive context to identify the deployed copy; never send Home Assistant credentials. General setup questions belong in GitHub issues or the built-in Feedback form.

## Send feedback without GitHub

If you can access a deployed Workbench copy, open **Feedback** in its connection manager or ask its installed plugin to submit a report. You receive a tracking ID and can check status and maintainer replies. No GitHub account or connected Home Assistant installation is required. Each deployed copy's reports go to that copy's configured maintainer; they are not automatically posted to this repository.

Feedback expires 90 days after submission. You can delete your own report and reply earlier. Expired reports are purged on feedback access; an unattended cleanup schedule is still pending verification.

## Setup and troubleshooting

- Start with the [README](../README.md) and [user guide](user-guide.md).
- For history and logbook questions, see the [history guide](history.md). Missing records do not prove that nothing happened.
- For connection and permission limits, see [security and limits](security-and-limits.md).
- If ChatGPT does not show a newly added tool, refresh your existing developer connection from ChatGPT Plugins when **Refresh** is offered, then start a new chat. Do not create a second copy just to refresh tools.

For an urgent problem with your physical home, use your own Home Assistant controls and appropriate local support. This community project does not promise a response time.
